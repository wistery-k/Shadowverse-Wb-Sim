# デフォルトデッキ

このディレクトリの `*.txt` は、アプリのデッキ一覧に「デフォルトデッキ」として表示されます。
アプリのデッキ構築画面の「エクスポート」で出力したテキストを、そのまま `<名前>.txt` として置けば追加できます。

```
名前: エルフテスト
クラス: エルフ
3 フェアリーテイマー
3 ベビーカーバンクル
...
```

- `#` で始まる行はコメントです
- カードの行は「枚数 カード名」です（カード名の代わりにカードIDも使えます）
- `npm test` で、すべてのファイルがスターターの構築ルール（40枚・同名3枚まで・クラス）を満たすか検査します
