## 書き方

- 実験を始めたら「進行中」に 1 行（問い・見込みの大きさ・試合数・合否の線）。終えたら消し、採否を `npm run ledger -- decide` で台帳に足し、
  詳しい記録を `docs/ai-notes/` のいちばん新しいファイルに書く（ai-notes.md「書き足し方」）
- 既定を変えたら「今の既定」と「追う数字」を直す。やめたこと・保留にしたことは、上の表に再開の条件と一緒に足す
- 不採用にした設定・経路・1 回きりのランナーは、決めたら消して [removed.md](removed.md) に 1 行足す（足す前に引く）。診断用・物差しの凍結した設定・打ち比べのランナーは残す
