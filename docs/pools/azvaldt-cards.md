# 前期のローテーション: カードごとの棚卸し

2026-11-13 に元データ（`data/pools/azvaldt/` の 3 つのファイルの元）の能力の文を読んで作った一覧。まとめと見込みは [azvaldt.md](azvaldt.md)。
スターターと同じ ID のカード（ベーシック 56 種とトークン 25 種）は能力も同じなので、もう書けている扱いにして除いた。

- 「要るもの」は、今の DSL（`src/engine/dsl.ts`）とエンジンに無い仕組み。（L）新しい仕組みでルールの確認が要る、（M）新しい誘発・効果・記録で状態に項目が増える、（S）条件・対象・値・小さな効果の追加
- 能力の文を正規表現で調べて付けた見込み。「書ける」に入れたカードも、能力を書いてテストを通すまでは確かではない（取りこぼしがあれば、そのとき足す）
- 結晶・アクセラレート・信仰は、能力の文ではなく公式データの特殊効果（`specials.json`）で付けた。クレストは、それを与えるカードの弾とクラスに入れた
