# 試合の記録（プロの試合を手で入れる）

プロの試合（配信のアーカイブの動画）を、見ながらクリックでシミュレータに入れる画面と、その記録の形。検討モード（`docs/STATE.md` の案 D）の土台。
開発サーバー（`npm run dev`）の「試合の記録」タブだけで出す。公開サイトには出さない。

- 画面: `src/ui/MatchRecord.tsx`（と `MatchRecord.css`）
- 記録の形・たどり方・引いたカードとランダムな結果の決め方: `src/record/record.ts`
- プロのデッキ: `src/record/decks.ts`（`data/pools/azvaldt/decks/` の 84 個を読む）
- 前期のローテーションのカードの表: `src/record/pool.ts`（エンジンのカードの表に足す。公開サイトの画面はスターターのまま）
- テスト: `tests/match-record.test.ts`

## 何のためか

入れた記録は AI の版に依らない。段階 4 で学び直した AI が「プロの手とどれだけ合うか」を確かめ、プロと違う手を選んだ局面から問題集の候補を拾うのに使う（採否は今までどおり勝率）。
入れている途中で、エンジンの結果が動画と合わないところが見つかれば、ルールやカードの間違いの報告になる（「動画と違う」の印）。

## 入れ方

1. **試合を選ぶ**: 大会、先攻のチームとクラス、後攻のチームとクラスを選ぶ（デッキはこれで決まる）。メモ（動画のどのあたりか）は任意。「始める」
2. **初期手札**: 席ごとに、最初の 4 枚をデッキの一覧から選ぶ。一覧はコストごとの行に分け、行の中はフォロワー（攻撃力/体力）・スペル・アミュレットの順で、枚数を添える
3. **マリガン**: 替えるカードをクリックして「決定」。替えて引いたカードを、デッキの残りの一覧から選ぶ
4. **ターン**: 対戦画面と同じに、手番の側の手をクリックで入れる（両方の手札が見える。カードをクリックすると、できることが出る）
   - 引いたカードは、そのデッキの残りの一覧から 1 枚ずつ選ぶ。ターンの最初のドローも、能力で引くときも同じ。相手が引くときも聞く。
     選んでいる間、盤面は「その手を打った後の見込み」（ターン終了時の効果や、次のターンの始めの後）を出し、まだ決めていない引いたカードは伏せる（青い枠がいま選ぶカード）
   - ランダムな結果（対象、出るカードなど、運で決まるところ）は、ありうる結果の一覧から、動画で起きたものを選ぶ。太字が結果ごとの違い、薄い字はどの結果でも同じところ。出ていなければ「もっと探す」
5. **終わり**: リーダーの体力が 0 になるか、「リタイア」で負けた側を選ぶと終わる。「記録を保存」でファイル（`<大会>_<チーム>-<クラス>_vs_<チーム>-<クラス>_<日時>.json`。クラスは `witch` 等の ID）に書き出す

そのほか:

- 「← 戻す」「やり直す →」で何手でも戻せる。戻した所から別の手を入れると、その先の手順は消える。手順の一覧（カードの詳細の下）をクリックしても、その局面に戻る
- 途中の経過はブラウザ（`localStorage` の `svwb-sim:match-record:v1`）に自動で残る。開き直すと続きから。残すのは 1 試合だけなので、新しい試合を始める前に書き出す
- 「動画と違う」: エンジンの結果が動画と合わない局面に、メモ（任意）を付けて印を残す。印の付いた局面は、あとでルールとカードの確認に回す
- 「手で直す」: 合わないまま先へ進めるように、局面を手で直す（リーダーの体力・PP・EP・SEP・墓場、フォロワーの攻撃力・体力・進化、アミュレットのカウントダウン、
  カードを場・手札・山札・墓場に動かす・消す、そのデッキのカードとトークンを手札・場に加える）。能力は働かない。直した局面はそのまま手順に残る。
  効果の解決の途中（選ぶ・モードを選ぶの途中）では直せない
- 「書き出した記録を開く」で、書き出したファイルから続きを入れられる
- 文字を打つのはメモだけ

## 引いたカードとランダムな結果の決め方

エンジンは変えていない（ふつうの試合の結果・ゴールデン・物差しの指紋は変わらない）。

- **引いたカード**: エンジンは山札の上から（条件付きで引くときは、上から見て最初に合うカードを）引く。そこで、決めた引いたカードを山札の上に並べてから手を打つ。
  どの手で何枚引くかは打つまで分からないので、打ってみて「引いたのに、まだ決めていないカード」があれば聞き、並べ直して打ち直す（手番の側から、1 枚ずつ）。
  手札が上限で墓場に行ったカードも、引いたカードとして聞く。アポカリプスデッキのように山札ごと入れ替わる手では聞かない。
  手札から山札に戻して、同じ手の中で引き直したカード（陽光の耳飾りなど）も、引いたカードとして聞く（手札の記録 `handLog` の、山札の一番上から引いた数で見分ける）。
  選べるのは、その手を打った後の山札と、まだ決めていない引いたカード（戻したカードも入る）
- **ランダムな結果**: 乱数の状態を変えて同じ手を打ち直し（まず 12 回。結果が分かれたら 120 回）、見える結果（盤面・手札・山札・クレスト・墓場・PP 等。
  この手で引いたカードは、どれを引いたかを見ない）ごとにまとめて並べる。選んだ結果を出した乱数の状態を、手順の `rng` に残す。
  同じ名前のカードが場に 2 枚以上あるときは、どれが選ばれたかを「左から N 枚目」で出す。ただし、同じターンに場に出た同じカード（攻撃力・体力・能力も同じ）の
  どれが選ばれたかは区別しない（どれでも同じ局面になる。「左から N 枚目」はそのうちの 1 つ）。一覧では、ほかの結果と違うところを太字、どの結果でも同じ場・リーダーの変化を薄い字で出し、
  そのほかの同じ変化（手札のスペルブースト等）は件数だけ出す。まれな結果は取りこぼしうるので「もっと探す」（500 回ずつ足す）がある
- **山札を切り直してから引く手**（手札を山札に戻して切り直してから引く等）: 並べた順が切り直しで崩れるので、選んだ見える結果のまま、決めた引いたカードを引く乱数を探す（5000 回まで）。
  見つからなければ「引く結果が見つかりません」と出る（その手では引けないカードを選んだか、まれすぎる）。そのときは「最後に選んだカードを外す」で選び直すか、
  近い結果で進めて「手で直す」で直し、「動画と違う」の印を付ける

## 記録の形

1 試合 1 ファイルの JSON（`src/record/record.ts` の `MatchRecord`）。版が上がったら `version` を上げる。

```jsonc
{
  "format": "svwb-match-record",
  "version": 1,
  "meta": {
    "event": "<大会のフォルダの名前>", "eventName": "<大会の名前>",
    "seats": [{ "deck": "<大会>/<チーム>_<クラス>", "team": "<チーム>", "cls": "<クラス>" }, { ... }],  // 席 0 が先攻
    "memo": "動画のどのあたりか（任意）",
    "commit": "<入れたときのコミット>", "dirty": false,   // dirty: コミットしていない変更があったか
    "createdAt": "…", "updatedAt": "…"
  },
  "decks": [["<カード ID>", ...40 枚], [...]],   // プロのデッキと同じもの（読むときに確かめる）
  "seed": 123,                                  // createGame のシード（席 0 が先攻になるもの）
  "steps": [ ... ],                             // 最初の局面からたどる手順（下）
  "turns": [{ "turn": 1, "step": 4, "state": { ... } }, ...],  // 各ターンの最初の局面（書き出すときに付ける）
  "result": { "winner": 0, "reason": "leader" }  // leader / deck（山札切れ）/ retire。終わっていなければ null
}
```

手順（`steps`）の種類:

| `kind` | 中身 | たどるとき |
| --- | --- | --- |
| `hand` | `player`、`cards`（初期手札のカード ID を 4 枚） | 手札と山札のカードを入れ替える |
| `action` | `action`（エンジンの行動）、`draws`（席ごとの、決めた引いたカード）、`rng`（打つ前に置き換える乱数の状態）、`outcome`（選んだランダムな結果の説明。見る人のため） | `draws` を山札の上に並べ、`rng` を置き換えてから打つ。決めたカードが引かれなければ誤り |
| `edit` | `label`（何を直したか）、`state`（直した後の局面） | 局面をそのまま置き換える |
| `mark` | `note`（「動画と違う」のメモ） | 局面は変わらない（この時点の局面に付く印） |
| `retire` | `loser`（リタイアした側） | 局面は変わらない。試合はここで終わり |

- たどるのは `replay(record)`（最初の局面から手順を順に当てる）。エンジンやカードの能力を後で直すと、たどれなくなる手順や結果の変わる手順がありうる
- `turns` は、各ターンの最初の局面（メインフェイズで、ターンが変わった直後）を状態の JSON でそのまま持つ。エンジンを直しても動画どおりの局面が残り、検討はこの局面から始められる
- ブラウザに残すもの（自動の保存）には `turns` が無い。書き出すときに作る
