### 土の印 ✅ ユーザー確認

- 【土の印】を持つアミュレット（魔女の錬金釜、大地の魔片）はスタック（数）を持つ
- 「土の印を+Nする」: 場に【土の印】アミュレットがあればそのスタックを+N。無ければ大地の魔片を1枚場に出し、スタックをNにする
- 【土の印】アミュレットが場に出たとき、すでに他の【土の印】アミュレット（スタックn）があれば、元からある方を消滅させ、新しく出た方のスタックを+nする。このため1人の場の【土の印】アミュレットは最大1枚
- 魔女の錬金釜・大地の魔片を場に出したときのスタックの初期値は1 ✅ 公式の用語説明（土の印）
- 【土の印】を持つカードは能力で破壊できず、相手の能力で選べない ✅ 公式の用語説明（土の印）。エンジンは未対応。スターターのプールで【土の印】を持つのはウィッチのアミュレットだけで、アミュレットを能力で破壊するのはビショップの終焉のスカルフェイン（自分のアミュレット）だけ、相手のアミュレットを選ぶ能力も無いので、結果は変わらない
- 土の秘術_N: 場にスタックN以上の【土の印】アミュレットがあればスタックを-Nして能力が働く。足りないか無ければ何も起きず、紐づいた能力も働かない
- 「自分の場の土の印の数」はスタックの値 ⚠️（推定）
- スタックが0になった【土の印】アミュレットは破壊される ✅ ユーザー確認（2026-10-09）。土の秘術でスタックを支払った時点で破壊し、その後に紐づいた能力が働く（処理順もユーザー確認済み）

### 融合 ✅ ユーザー確認

- 融合は手札のカード同士で行う。【融合】の後に書かれた種類のカードを、手札から何枚でも素材にできる（例: フューチャー・コアにはアーティファクト・アミュレットを融合できる。スターターではフューチャー・コアとパスト・コアのみ）
- PP は使わない。1つのカードの融合は1ターンに1回まで
- 「融合したカードのコストの合計」は、1回の融合で使った素材のコストの合計
- デストロイアーティファクトαの「融合した種類が2」は、これまでに融合した種類の累計（複数ターンにまたがって β と γ を融合した場合も変身する）
- 変身前に融合した素材の種類は数えない ⚠️（推定）
- 素材にしたカードは墓場に入らない ✅ 公式の用語説明（融合）

### 墓場

墓場はカード置き場ではなくカウンターとして扱う。✅ ユーザー確認

- 破壊されたカード、使ったスペル、手札上限で溢れたカードなどで増える
- 「消滅」したカードは墓場に入らない
- リアニメイトの対象は墓場にあるフォロワー（手札上限で溢れたカードは対象外）。手札から捨てたカードは含まない ✅ ユーザー確認

### 公式の Q&A から分かること ✅ 公式データ

- ランダムに選ぶ候補にフォロワーとリーダーが混ざるときは、それぞれ等しい確率で選び、繰り返す能力では 1 回ごとに選び直す（天司長の後継・サンダルフォン、猛る《戦車》・オルオーン）
- ターン開始時（天司長の後継・サンダルフォン）: 「クレストの能力 → 直接召喚 → ドロー」と「カウントダウン（0 で破壊）→ 直接召喚 → 破壊されたアミュレットのラストワード → 直接召喚されたときの能力（手札に戻る）→ ドロー」。ドローが最後なのは今のエンジンと合う。2 つを合わせると、クレストの「ターン開始時」の能力は、カウントダウンで破壊されたカードのラストワードより先（エンジンは 2026-11-14 からこのとおり。11章の未確認の一覧の「ターン開始時の処理順」）。クレストのカウントダウンとアミュレットのカウントダウンの前後は、この Q&A では決まらない（ユーザーが実機で確かめた 2026-11-14: クレストが先。11章の「ターン開始時の処理順」）
- 直接召喚されて手札に戻ったカードのコストは元に戻る（ほーちゃんでコスト 3 にしたサンダルフォンは、戻ると 6）
- 自分のターン終了時は、場のカードの能力（混迷の監獄・アズヴォルトが自分を破壊）→ デッキからの直接召喚（途絶した輪廻・ゼラエル）→ 破壊されたカードのラストワードの順
- 「受けるダメージを+1する」は重なり、ふっとばしのダメージにも足される（全一の王・ベルゼバブ）。世界の味方・ゾーイの「受ける1以上のダメージを0にする」は相手のクレストのダメージも 0 にする
- クレスト：充つ《恋人と節制》・ミルティオ＆ルーゼン（自分のフォロワーの【ファンファーレ】や【エンハンス】は働かない）の間は、エンハンスを持つカードも普通のコストでプレイする。「これの【ファンファーレ】を働かせる」も働かない
- 手札が 9 枚で引いた（溢れた）カードでは「カードを引いたとき」は働かない（窮鼠の斎女、クレスト：霧巻花・クキシロ）
- 美粧の乙女・クロエの【エンハンス_8】で、場が埋まっていて選んだフォロワーが出せないときも、クロエは手札に戻る
- 赤色流しは、手札か相手の場のフォロワーのどちらかが選べないときプレイできない。侵略されし世界は手札が 0 枚でもアクトできる（何も起きない）
- 森林の罠は、相手が一度に 3 枚出しても 1 枚目だけを破壊する。没入の実験体が一度に 2 枚出ると、2 枚目は 1 枚目を「場に出た」と数える
- 腐臭のゾンビ: 3 ダメージを与える能力が 2 つ続けて働くとき、1 つ目で破壊されたゾンビのラストワードは 2 つ目の後に働くので、出たゾンビはダメージを受けない（11章の FIFO のキューと合う）
- 翼天の変貌・オルメリオの「下記の能力から順に1つ」は、(3) の次は (1) に戻る
- 「1ターンに2回攻撃できる。」を得ても、3 回攻撃できるフォロワー（超進化した枯渇の神魔・アルメス）は 3 回のまま（大いなる回帰、クレスト：飛躍の姉妹・ベルディリア＆カステル）
- 天晶の深淵の X/Y/Z は、信仰値の数だけ X・Y・Z から等しい確率で 1 つ選んで 1 ずつ足す
- 空慕う帰還者・カシウスは、手札にアーティファクト・フォロワーが無くても働き、0 ダメージを与える
- 清く正しい修道女・ラムレッダ: 自分のターン終了時に（土の理・ガレヲンの能力で）進化しても、同じターン終了時の「これが進化後なら」は働かない
- 大遊戯世界は、相手の場のカードも「場にそれ以外の元のコストXのカード」に数える。残虐の炸裂は、体力が同じならお互いのリーダーに与える
- 吉祥蛙: クレスト：麗金花・ウンケイ（自分のターン終了時に『輝く金貨』を手札に加える）を持っていても、ターン終了時に手札のスペルが 1 枚なら「相手の場のフォロワーすべてに5ダメージ」は働かない。（ここからの推論: ターン終了時の能力の「〜なら」は、ほかのターン終了時の能力が解決する前に見る。清く正しい修道女・ラムレッダの Q&A とも合う。今のエンジンは解決するときに見るので、実装のときに確かめる）
- 壮美なる明越花: 場のフォロワーそれぞれが、デッキのフォロワーから独立に（同じカードも選ばれうる）等しい確率で 1 枚を選んで変身する
- 昔日の天秤・マーロン: X の「自分の場のフォロワーの枚数」はマーロン自身を数える（相手の場に 5 枚・自分の場に 0 枚でプレイすると X は 4）
- 最古の獄卒: 相手の場に『暴食のアナテマ・ララアンセム』（このプールに無いカード）だけがいるときも、「相手の場の選んでいないフォロワーからランダム1枚に2ダメージ」は働く。ララアンセムの能力はデータに無いので、どう読むかは質問 23
- デストロイアーティファクトα: β を融合した次のターンに γ を融合しても、イクシードアーティファクトΩに変身する（8章「融合」と同じ）

### 公式の用語説明から分かること（ユーザー提供 2026-11-13） ✅ 公式

上の表に入れたもののほか、このプールで要るもの。用語説明は今のゲームの説明なので、スターター（当時）の決まりとの違いは別に確かめる（下の「スターターへの影響」）。

- **リーダーエリア**: 持ったクレストと信仰を置く。5 つまで。同名のクレスト・同名の信仰は重複して置けない（質問 10 の答えと合う）。5 つ埋まっているときに得たクレストは得ない（質問 28 の答え）
- **ダメージ**: ダメージを増減させる能力（「受けるダメージを+1する」）は、ダメージを特定の値にする能力（「受ける4以上のダメージを3にする」「受ける1以上のダメージを0にする」）より先に働く。ダメージは 0 より小さくならない。バリアは最後（質問 12 の答え）
- **コピー**: 受けたダメージとかかっている効果は引き継ぐ。このターンに攻撃・アクトしたかどうかは引き継がない（質問 8 の答えと合わせて、バフ・進化・コストの変化も引き継ぐ）
- **選ぶ**: 選ぶ能力を持つスペルは、指定された数すべてを選べるときだけプレイできる。選ぶ【ファンファーレ】を持つフォロワー・アミュレットは、すべてを選べなくてもプレイでき、できる限り選んで能力が働く（最古の獄卒の Q&A と合う。質問 23 はこれで答えとする。11章の「能力は不発」との違いは「スターターへの影響」）
- **連携**・**コンボ**: コンボはそのカード自身も数え、連携はそのカード自身を数えない（質問 3 の答え）
- **エンハンス**: 複数のエンハンスを持つときは、残りの PP 以下で最大のエンハンスの値だけ PP を払い、それ以下の値のエンハンスもすべて働く
- **モード**: 働く条件を満たしていないモードも選べるが、その能力は働かない
- **ファンファーレ**: 手札からプレイして場に出たときだけ働く。手札やデッキから直接場に出したとき、生成して場に出したときは働かない（直接召喚と同じ）
- **変身**: 受けたダメージ・かかっている効果、このターンに攻撃・アクトしたかどうかは引き継がない。フォロワーに変身したら次のターンから攻撃できる。変身は「場を離れる」に入らない
- **デッキに戻す・手札に戻す**: 手札からデッキに戻したときはかかっている効果を引き継ぐ（11章と合う）。場から手札に戻したときは、受けたダメージ・かかっている効果を引き継がない
- **ダメージを割りふる**: 場に出たのが古いフォロワーから順に、体力の値までを割りふる。余りは、対象にリーダーが含まれていればリーダーに、無ければ最後のフォロワーに与える。変身しても順番は変わらない
- **融合**: 融合された素材は手札から取り除かれ、墓場は増やさない
- **場に出す**: 手札やデッキから場に出すとき、場の上限を超えるカードは移動しない。生成して場に出すとき、上限を超えるカードは出ず、墓場も増やさない
- このプールのカードに無いもの: 証拠、勝利のカード
