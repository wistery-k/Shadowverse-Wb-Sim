## 1. フォーマット

| 項目 | 内容 | 状況 |

## 3. クラス

エルフ / ロイヤル / ウィッチ / ドラゴン / ナイトメア / ビショップ / ネメシス の7クラス＋ニュートラル。✅ 公式データ

公式データのクラス番号: 0 ニュートラル、1 エルフ、2 ロイヤル、3 ウィッチ、4 ドラゴン、5 ナイトメア、6 ビショップ、7 ネメシス

## 4. 対戦の基本

| 項目 | 内容 | 状況 |
| --- | --- | --- |
| リーダー体力 | 20。0以下で敗北 | ⚠️ |
| 先攻・後攻 | ランダムに決定 | ⚠️ |
| 初期手札 | お互い4枚 | ✅ ユーザー確認 |
| マリガン | 4枚のうち入れ替えるカードを好きな枚数選んで脇に置き、山札からその枚数を引く。最後に脇に置いたカードを山札に戻して山札をシャッフルする | ✅ ユーザー確認 |
| 後攻の追加ドロー | 後攻は最初のターン開始時に追加で1枚引く | ⚠️ |
| ドロー | 各自ターン開始時に1枚。先攻1ターン目もドローするか要確認 | ⚠️ |
| 山札切れ | 山札が0枚のときに引こうとすると敗北 | ⚠️ |
| 手札上限 | 9枚。超過して引いたカードは墓場へ | ⚠️ |
| 場の上限 | フォロワー・アミュレット合わせて5枚。満杯時の召喚は不発 | ⚠️ |
| PP | 自ターン開始時に最大PPが1増え（上限10）、PPが全回復 | ⚠️ |
| 決着 | リーダー体力0、山札切れ、投了。両者同時の扱いは要確認 | ⚠️ |

## 5. カードの種類

| 種類 | 内容 | 状況 |
| --- | --- | --- |
| フォロワー | 攻撃力/体力を持ち場に出る。進化できる（公式データ type 1） | ⚠️ |
| スペル | 使用して効果を発揮し墓場へ（type 4） | ⚠️ |
| アミュレット | 場に出る（type 2） | ⚠️ |
| カウントダウンアミュレット | 【カウントダウン_N】を持つアミュレット（type 3）。自ターン開始時に1減り、0で破壊 | 種類は✅ 公式データ、減少タイミングは⚠️ |

## 6. 攻撃

| 項目 | 内容 | 状況 |
| --- | --- | --- |
| 召喚酔い | 場に出たターンは攻撃できない（疾走・突進・進化を除く） | ⚠️ |
| 攻撃回数 | 各フォロワーは1ターンに1回 | ⚠️ |
| 交戦 | フォロワー同士は互いの攻撃力分のダメージを同時に与え合う | ⚠️ |
| リーダーへの攻撃 | 攻撃を受けたリーダーは反撃しない | ⚠️ |
| 守護 | 相手の場に守護がいる場合、守護以外（リーダー含む）を攻撃できない | ⚠️ |

| 項目 | 内容 | 状況 |
| --- | --- | --- |

| 進化 | EP を1消費し、自ターンに自分のフォロワーを1体進化 | ⚠️（EP消費量） |
| 進化の効果 | 一律 +2/+2。そのターン相手フォロワーに攻撃可能（突進相当） | ✅ ユーザー確認 |

| 超進化 | SEP を1消費して自分のフォロワーを1体超進化 | ⚠️（SEP消費量） |
| 超進化の効果 | +3/+3。自分のターン中はいかなるダメージも受けず、効果で破壊されない | ✅ ユーザー確認 |
| 超進化の効果（攻撃） | そのターン相手フォロワーに攻撃可能（突進相当） | ✅ ユーザー確認 |
| 超進化解禁 | 先攻7ターン目以降・後攻6ターン目以降 | ✅ ユーザー確認 |

## 8. キーワード能力

公式データの `skill_names` にある全キーワード（第2弾以降のものも含む）。
スターターのカードプールで使われるものは、全カードの変換後に確定する。

ファンファーレ / ラストワード / 進化時 / 超進化時 / 攻撃時 / 交戦時 / 守護 / 疾走 / 突進 / 潜伏 / 必殺 / ドレイン / 威圧 / バリア / オーラ / 覚醒 / スペルブースト時 / カウントダウン / ネクロマンス / 土の秘術 / 土の印 / エンハンス / リアニメイト / アクセラレート / 直接召喚 / 結晶 / 融合 / 連携 / コンボ / モード / アクト / クレスト / 信仰 / 奥義 / 解放奥義 / アポカリプスデッキ / マゼルベインデッキ

能力テキストではキーワードの数値を `【コンボ_3】` `【エンハンス_4】` `【カウントダウン_2】` のように書く（公式表記のまま）。

## 9. クレスト

一部のレジェンドが「自分は『クレスト：〇〇』を持つ」効果を持つ（リーダーに付く継続効果と推定）。
クレストの効果テキストは元データに含まれていない。⚠️ 要データ

対象: 自然の妖精姫・アリア、常在戦場・カゲミツ、黎明の錬金術師・ノノ、灼熱のアナテマ・バーンドナイト（相手が持つ）、闇の賞金稼ぎ・バルト、大いなる熾天使・ラピス、新たなる少女・エース

## 10. 効果の解決順

すべて ⚠️ 未確認。実装前に確認する。

- 複数の誘発能力が同時に発動したときの順序（場に出た順？ターンプレイヤー優先？）
- ラストワードと「破壊されたとき」系の処理順
- 同時に体力0以下になったフォロワーの破壊順
- ファンファーレ中に場が埋まった場合の扱い
