## ルール

### 山札に戻したカードのスペルブーストを維持する

- 公式ルール（ユーザー確認、2026-10-12）: 手札から山札に戻したカードは、スペルブーストされた回数を維持する。オーバーディメンションを使うスペルウィッチで重要
- 現状: 山札のカードは `CardRef`（`iid` と `cardId` だけ）で持つため、山札に戻すとブースト回数が消え、引いたときに `boosts: 0` で作り直される（`src/engine/effects.ts` の `returnToDeck`、`src/engine/state.ts` の `drawCards` / `newHandCard`）
- 影響するカード: `returnToDeck` を使うカード（オーバーディメンション、グリードケルブ・ルビィ、ウィッチ・ロイヤルの手札を山札に戻すカード）
- 実装の検討事項: 山札のカードにブースト回数を持たせる（状態の型・`cloneState`・`src/ai/determinize.ts` の山札の並べ直しへの影響）。コスト変化など他の手札での変化も維持されるかは未確認
