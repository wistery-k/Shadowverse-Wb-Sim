# 足切りを通ったが 3 万局面で打ち切った局面

- 96 試合（リノセウスエルフ vs 6 デッキ × 8 シード × 先後、seed = 900000 + g×13 + エルフの席）で、各ターンの最初の全探索の局面を集め、今の設定 で全探索し直した
- 今の設定: 上限 = リノセウス 1 回・2 回の式の大きい方（3 回出せるかもしれなければ 3 回の式も）。ベイルは 0 コストまで下がりうるときだけ 0 コストとみなす。1 回（2 回）の上限が届かなければ、リノセウスを 2 回（3 回）以上出す手順だけを探す。リノセウスでリーダー以外を攻撃しない。相手の場に守護がいる間はリノセウスを出さない。攻撃力が余裕より大きい場のフォロワーはリーダーしか攻撃しない。出すと上限が届かなくなるバックウッド・リリィ・燐光の岩・手札の聖樹の杖は出さない。エクストラPPは新しく出せるカードが増えるときだけ使う。上限 3 万局面
- 3 万局面を超えて打ち切ったもの 3 件（リーサルの有無は不明）。調べきってリーサルが無かった 10 件は `rhino-exact-no-lethal.md` にある
- 「超進化」は、このターンに超進化できるか（先攻 7 ターン目・後攻 6 ターン目から、SEP が残っていて未進化）
