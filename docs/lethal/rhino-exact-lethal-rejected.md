# 全探索でリーサルを見つけたのに通らなかった 2 試合（アマリアロイヤル戦）

- 対戦: リノセウスエルフ（rhino、全探索のリーサル探索あり。ブランチ `claude/project-thread-makwol`）vs アマリアロイヤル（探索 AI）
- `npm run rhino-compare -- --games 50` の 600 試合のうち、全探索でリーサルを見つけたのに負けた 2 試合

## 原因（2 試合共通）

リーサル探索は、相手の手札や乱数を仮に決めた局面（決定化）で手順を探します。見つけた手順は、別の決定化 2 つでも勝てるか確かめ、勝てなければ捨てます（`findLethal` の `samples: 3`）。

全探索が見つけた手順は、どちらも最初に **虫の知らせ** を打ち、そのランダム 2 ダメージで守護のスティールナイトを倒す前提でした。乱数が変わると別のフォロワーに当たるので、確認で捨てられました。そのあとは普通の探索 AI がリノセウスを出さずにターンを終えています。

- 1 試合目（seed 900234）: **虫の知らせを使わない確実なリーサルがあった**のに、全探索は先に見つかった運頼みの手順を返していた
- 2 試合目（seed 900443）: 虫の知らせを使わないリーサルは無い。乱数を 20 通り変えると、15 通りでリーサルあり（虫の知らせが当たるかどうか次第）

## 1 試合目: seed 900234（g=18、エルフ後攻）、エルフ 7 ターン目

```
エルフ: 体力 19/20  PP 7/7（エクストラPPあり）  EP 0  SEP 1  コンボ 0
  手札(8): 虫の知らせ、殺戮のリノセウス、ベビーカーバンクル、煌撃の戦士・ベイル、妖精の招集、
           ピュアクリスタリア・リリィ、フェアリー、聖樹の杖
  場: 聖樹の杖
相手: 体力 10/20
  場: 勇猛のルミナスランサー 1/2、卓越のルミナスメイジ 1/3、
      スティールナイト 5/5 [突進・守護]（超進化・攻撃済）、スティールナイト 2/1 [突進・守護]（攻撃済）、
      スティールナイト 2/2 [突進・守護]
```

### 全探索が見つけた手順（運頼み）

虫の知らせ → 妖精の招集 → フェアリー ×3 → ベビーカーバンクル（フェアリーを戻す）→ カーバンクル超進化 → フェアリー → エクストラPP →
フェアリー・フェアリー・カーバンクル・フェアリーでスティールナイトを攻撃 → ベイル（スティールナイト）→ リノセウスで顔

虫の知らせのランダム 2 ダメージが守護に当たる前提なので、確認で捨てられた（実際の乱数では通っていた）。

### 虫の知らせを使わない確実なリーサル（相手 10 点）

1. 妖精の招集（コンボ 1）
2. フェアリー ×3（コンボ 4）
3. ベビーカーバンクル: フェアリーを戻す（コンボ 5）
4. フェアリー（コンボ 6）
5. 聖樹の杖をアクト: フェアリーを戻す
6. ベビーカーバンクルを超進化（PP 3 回復）
7. フェアリー（コンボ 7）→ エクストラPP
8. フェアリーでスティールナイトを攻撃 → カーバンクルでスティールナイトを攻撃（超進化で倒して顔に 1、体力 9）→ フェアリーでスティールナイトを攻撃
9. 煌撃の戦士・ベイル（フェアリーが場を離れた分安くなっている、コンボ 8）: 残ったスティールナイトに 4 ダメージ
10. 殺戮のリノセウス（コンボ 9 → 9/2）で顔に 9 点

### 実際に打った手

ベイル（メイジ）→ フェアリー → リリィ（スティールナイトを体力 1）→ リリィ超進化（ランサー）→ フェアリー・リリィでスティールナイトを攻撃 → ターン終了（相手の体力 9）。17 ターン目に負け。

## 2 試合目: seed 900443（g=34、エルフ後攻）、エルフ 7 ターン目

```
エルフ: 体力 15/20  PP 7/7（エクストラPPあり）  EP 0  SEP 1  コンボ 0
  手札(8): 燐光の岩、虫の知らせ、フェアリーテイマー、フェアリー、自然の妖精姫・アリア、
           殺戮のリノセウス、ピュアクリスタリア・リリィ、燐光の岩
  場: 聖樹の杖、純粋なるウォーターフェアリー 3/3（進化）
相手: 体力 10/20
  場: ミリタリードッグ 4/1 [突進]（攻撃済）、卓越のルミナスメイジ 4/6（超進化・攻撃済）、
      スティールナイト 2/2 [守護] ×3
```

### 全探索が見つけた手順（運頼み）

（フェアリーの後）虫の知らせ（杖を戻す）→ 燐光の岩 → 森の神秘 → フェアリー → 燐光の岩をアクト（フェアリー）→ フェアリー超進化 → エクストラPP → リノセウス →
フェアリー 2 体でスティールナイトを攻撃 → ウォーターフェアリーで顔 → リノセウスで顔

虫の知らせが 3 体目のスティールナイトに当たって倒す前提。実際の乱数では別のフォロワーに当たり、2 体目のフェアリーの攻撃先が守護で塞がれて通らない。
虫の知らせを使わないリーサルは無く、乱数を 20 通り変えると 15 通りでリーサルあり。

### 実際に打った手

フェアリー → 虫の知らせ（フェアリーを戻す）→ リリィ（メイジ）→ リリィ超進化（ドッグ）→ フェアリー → 舞い踊る妖精 → 守護を処理してターン終了（相手の体力 9、場は空）。17 ターン目に負け。
