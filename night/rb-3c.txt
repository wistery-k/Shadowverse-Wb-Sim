# ランダムな手を枝に移す学び直しの副の比べ（回すかはユーザーが選ぶ）: N 対 対照（同じ入力・同じ λ 0.7・同じ 3 エポックで、r7-1 のデータから学んだ版）。
# 計画の 4. の副（docs/ai-notes/15-2026-11-22.md「ランダムな手を枝に移す」）。主（night/rb-3.txt。N 対 R7）では、N と R7 はデータの形（ランダムな手を枝に移したか）と
#   エポック数（N は 3、R7 は --best 1 が選んだ 1）の両方が違う。この比べはエポック数をそろえて、データの形だけの効果を分ける。
#   N が λ 0.7・1 エポックなら主と同じなので回さない決まりだった。N は λ 0.7・3 エポック（night/rb-3.txt の先頭）なので、時間を添えてユーザーに出す
#
# 対照: R7（I）を学んだ r7-1 の学び（night/r7-1.txt の 4.）と同じ引数で、エポックごとの重みを書き出し（--epochOut）、3 エポック目の版に間引きと属性をかけたもの。
#   --byTurn 1 は学びを変えない（同じモデルを書く）。--best 1 の --out（@/it.json）は R7 の写しと同じになるはずなので、確かめに使うだけ
#
# ---- 回す前に決めた線（主と同じ。この晩の後には変えない）----
# N 対 対照、84 個のデッキ、席を入れ替えた 4 万試合（g0〜19999。主と同じシード、± 0.18 ほど）
#   強さ: 差 − 2 SE > −0.3 なら「落とさない」、差 − 2 SE > 0 なら「上げる」、差 + 2 SE < 0 なら「下げる」、どれでもなければ「分からない」
#   この比べは採否を決めない（採否は主で決める）。データの形の効果の大きさとして記録する
#
# 見込み（PC、svwb-docker・28 スレッド）: r7-1 の I の学びの実測（3 エポック 666 秒）、間引き 30 秒・属性 10 秒・写し 10 秒、
#   4 万試合は r7-3 の compare の 0.215 秒/試合（2 万試合 1 時間 12 分）で 2 時間 23 分。合わせて 2 時間 35 分ほど。主（rb-3）とは別に積める（rb-2・r7-1 の回のフォルダだけを読む）
# 朝: 止まったときのまとめを push してもらい、ingest する
# 回の名前は rb-3c（plan に --name rb-3c を付ける）

# 1. 対照の学び（r7-1 の I と同じ引数に --epochOut・--byTurn 1 を足したもの）と、3 エポック目の版の間引きと属性
td train --impl rust --model @run:r7-1/v0.json --data @run:r7-1/s-{1..20}.jsonl.gz --out @/it.json --epochOut @/it-e{e}.json --epochs 3 --lr 0.0003 --l2 0.001 --best 1 --bestOn end,imagined --ivRes 0 --base zero --lethalHead survival --dropInputs oppBoardCountdown,myCrestCountdown,oppCrestCountdown,myCrestStacks,oppCrestStacks --byTurn 1 --est 670
td prune --impl rust --model @/it-e3.json --data @run:r7-1/s-{1..20}.jsonl.gz --out @/ip-e3.json --est 30
td attr --model @/ip-e3.json --out @/i3.json --keepA 0 --est 10

# 2. N を写す（主と同じ写し方）
td extend --model @run:rb-2/n7-e3.json --out @/n.json --est 10

# 3. N 対 対照（4 万試合）
compare 20000 '{"valueNet":"@/n.json","potentialNet":"rust/engine/yardstick/pool-r4-potential.json","opponentSearch":{"beamWidth":8,"maxDepth":8,"extraEval":true,"ownWeights":true},"imaginedInput":false}' '{"valueNet":"@/i3.json","potentialNet":"rust/engine/yardstick/pool-r4-potential.json","opponentSearch":{"beamWidth":8,"maxDepth":8,"extraEval":true,"ownWeights":true},"imaginedInput":false}' 0 --decks @data/pools/azvaldt/sets/all84.txt --label 枝N対対照3エポック --est 0.215
