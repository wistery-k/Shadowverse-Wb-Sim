#   R6 は R1 から学び直しを重ねた版（もとはスターターの補正）の続きなので、0 から学ぶ大きい版だけだと「大きさ」と「0 から」が混ざる。
#   対照に、R6 と同じ 256・32 も 0 から学ぶ（審査の案）。

#      R6 の出発点（v0）と、語彙・ゾーン・数値の並びが同じになるのをクラウド環境で確かめた。足した語彙の行は 0 から、ほかは乱数から始まる（出力の重みが 0 なので、最初は補正 0）
#   1. Z256（対照）と Z512 を、R6（B）と同じデータ（回 r6-heads-1 の自己対戦 6 万試合、s-1〜20）・同じ引数で学び、間引き・属性で埋める。

#   PC とクラウド環境の比（B の学びが PC 11 分・クラウド環境 18 分で 0.62）を掛けて、学びは Z256 が 30 分・Z512 が 75 分ほど。--est は 2 割ほど足した。
#   メモリの山は 512・64 で 3GB ほど（クラウド環境の実測）。全部で 2 時間 10 分ほど（券は until=+3h で足りる）
# 朝: 止まったときのまとめを push してもらい、ingest する。モデル（z256.json・z512.json）は出口のファイルで共有フォルダへ（翌朝の数が読む）
# 回の名前は bignet-zero

# 0. 補正 0 のモデル（R6 と同じ入力の並び・a）を作り、新しいプールの語彙に広げる
td init --hidden 256,32 --a 0.0126253 --seed 1 --out @/i256.json --est 20
td extend --model @/i256.json --vocab @data/pools/azvaldt/sets/all84.txt --out @/z256-0.json --est 30
td init --hidden 512,64 --a 0.0126253 --seed 1 --out @/i512.json --est 30
td extend --model @/i512.json --vocab @data/pools/azvaldt/sets/all84.txt --out @/z512-0.json --est 60

# 1. Z256（対照: R6 と同じ形を 0 から）
td train --impl rust --model @/z256-0.json --data @run:r6-heads-1/s-{1..20}.jsonl.gz --out @/z256t.json --epochs 8 --lr 0.0003 --l2 0.001 --best 1 --bestOn end,imagined --ivRes 0 --base zero --lethalHead survival --dropInputs oppBoardCountdown,myCrestCountdown,oppCrestCountdown,myCrestFaith,oppCrestFaith,myCrestStacks,oppCrestStacks --est 2160
td prune --impl rust --model @/z256t.json --data @run:r6-heads-1/s-{1..20}.jsonl.gz --out @/z256p.json --est 40
td attr --model @/z256p.json --out @/z256.json --keepA 0 --est 15

# 2. Z512（大きい補正を 0 から）
td train --impl rust --model @/z512-0.json --data @run:r6-heads-1/s-{1..20}.jsonl.gz --out @/z512t.json --epochs 8 --lr 0.0003 --l2 0.001 --best 1 --bestOn end,imagined --ivRes 0 --base zero --lethalHead survival --dropInputs oppBoardCountdown,myCrestCountdown,oppCrestCountdown,myCrestFaith,oppCrestFaith,myCrestStacks,oppCrestStacks --est 5400
td prune --impl rust --model @/z512t.json --data @run:r6-heads-1/s-{1..20}.jsonl.gz --out @/z512p.json --est 80
td attr --model @/z512p.json --out @/z512.json --keepA 0 --est 30
