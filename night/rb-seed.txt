# N の学びの揺れの大きさを見る調べ（学びだけ。対戦なし。線にしない。rb-3 の版は変えない）: rb-2 の n7（λ 0.7）と同じ引数で、並べ替えの種（--seed）だけを 2・3 に替えて 4 エポックずつ学ぶ。
# 審査の求め（2026-11-27）: rb-2 の λ 0.7 は、エポック 3 だけが学んだ目標より 2.6 ポイント下に出て（1〜2 ターン目の帯）、4 以降は +1〜1.5 に落ち着いた。
#   エポックの終わりの重みが、出力の水準の揺れの途中を拾っているかを見る（docs/ai-notes/15-2026-11-22.md「ランダムな手を枝に移す」の 2 晩目の節の「審査の読み」）。
#   --seed は並べ替え（Fisher-Yates）の種だけで、確かめ用の分け方（試合番号で決まる）・出発の重み・目標の作り方は変えない。種 1（rb-2 の n7）の 1〜4 エポックは、8 エポックの学びの最初の 4 つと同じ
#   見る数: 各エポックの全体の予測の平均、手番の帯ごとの 予測 − 勝ち と 学んだ目標 − 予測（学びの報告の「手番ごとの確かめ用のターン末」の行）。
#   種の間のばらつきが、エポックの間の動き（2 ポイントほど）と同じ大きさなら、揺れの途中を拾っているという読みが当たり
#
# 見込み（PC、svwb-docker・28 スレッド）: rb-2 の n7 の学び（8 エポック）の実測 1605 秒から、読み込みを含めて 4 エポック 14 分ほどを 2 つで 28 分ほど
