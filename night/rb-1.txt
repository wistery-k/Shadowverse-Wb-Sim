# ランダムな手を枝に移す学び直しの 1 晩目（自己対戦だけ）: 本線の自己対戦をランダムな手なし（--eps 0）で打ち、ランダムな手は枝（td branch --first random）で後から生やす。
# ユーザーの案（2026-11-26、審査のスレッド）: 「自己対戦はランダム手無しで打って、局所解にハマるのを防ぐためのランダム着手は td branch で後から生やす（その枝の先は最後まで打つ）」。
#   狙い: どの局面の目標もランダムな手を通らないので、切らなくてよい（切ったところの値が出発の R6 の楽観を受け継ぐ問題が無い。docs/ai-notes/15-2026-11-22.md「切ったところの値も楽観していないか」）。
#   学ぶ世界（どちらもランダムに打たない）が、対戦の世界と同じになる。計画は docs/ai-notes/15-2026-11-22.md「ランダムな手を枝に移す」

# 学びと比べは 2 晩目（night/rb-2.txt。3 晩目の I の結果と r7-cut-1 の結果を見てから、先頭の決め方で引数を決めて書く）。この晩は学びに使う自己対戦と枝だけを作る
#   （自己対戦は出発の補正 v0 で打つので、I を採るか、λ・エポックをどうするかに関わらず同じデータになる）
#
# 自己対戦（本線）: r7-1 と同じ引数・同じ出発の補正（@run:r7-1/v0.json）・同じ試合番号の始まり（g7600000〜。デッキの組と確かめ用の試合の分け方が r7-1 と同じ）で、--eps 0.1 を --eps 0 にしたもの。試合は 39000
#   介入の試合（--iv 3 --ivZone both）も --eps 0 で打つ（介入はランダムな手と別の仕組みなので、R6・r7-1 と同じに残す）
# 枝: 本線の棋譜の試合ごとに、両方の席の自分のターンの最初のそれぞれを確率 0.1 で枝の場所にし（--rate 0.1。本線の --eps 0.1 のランダムな手と同じ数え方なので、
#   枝のターンの割合は r7-1 のランダムな手と同じ）、そこで --eps と同じ選び方の手（ターン終了を除く合法手から 1 つを同じ確率で）を打ち、その先を --eps 0 で最後まで打つ。
#   書くのは枝のターン末から（分かれた局面は本線の行にある）。打ち方と印は本線と同じ
#
# 見込み（PC、svwb-docker・28 スレッド）: r7-1 の自己対戦の実測 0.556 秒/試合に、クラウド環境で同じ 112 試合（g7600000〜）を打った比をかけた。
#   本線 --eps 0 は --eps 0.1 の 1.09 倍で 0.605 秒/試合・6 時間 33 分、枝は 0.39 倍（もとの試合 1 つあたり。枝 1.68 個）で 0.215 秒/試合・2 時間 20 分、合わせて 8 時間 53 分。
#   局面は 39000 × 231 = 900 万で、r7-1（6 万 × 168）の 9 割。本線を 6 万にすると 13 時間 40 分で一晩に収まらないので、本線を減らした
# 朝: 止まったときのまとめを push してもらい、ingest する。データ（s-{1..13}・b-{1..13}）は 2 晩目が @run:rb-1/ で読む
# 回の名前は rb-1（plan に --name rb-1 を付ける）

# 1. 本線の自己対戦（ランダムな手なし）
td selfplay --model @run:r7-1/v0.json --decks @data/pools/azvaldt/sets/all84.txt --games 39000 --start 7600000 --chunk 3000 --eps 0 --opp beam --sampling default --iv 3 --ivZone both --imagined 2 --searchValue 1 --lostLabel 1 --potential rust/engine/yardstick/pool-r4-potential.json --searchOptions data/pools/azvaldt/search-options.json --out @/s-{k}.jsonl.gz --est 0.605

# 2. 枝（ランダムな最初の手。その先はランダムな手なし）
td branch --first random --rate 0.1 --model @run:r7-1/v0.json --from @/kifu --games 39000 --start 7600000 --chunk 3000 --eps 0 --opp beam --sampling default --imagined 2 --searchValue 1 --lostLabel 1 --potential rust/engine/yardstick/pool-r4-potential.json --searchOptions data/pools/azvaldt/search-options.json --out @/b-{k}.jsonl.gz --est 0.215
